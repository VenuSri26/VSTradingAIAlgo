# VSTradingAI 2.2.0 RC1

This release adds a production-style application shell around the AWS-validated dashboard.

## User-visible improvements

- Sidebar navigation on desktop and bottom navigation on mobile.
- Dedicated workspaces for market overview, trading, paper portfolio, analytics, operations, and settings.
- Paper portfolio summarizes open trades, closed trades, net P&L, and win rate.
- Operations Console retains setup approval, paper execution, monitoring, metrics, alerts, and Zerodha health.

## Compatibility

- No trading formulas were changed.
- No backend API was removed.
- Same-origin REST and WebSocket URLs remain AWS-compatible.
- Live Zerodha order execution remains disabled.
