# V6.4.0 RC1

Cumulative release based on V6.3.0 RC1.

## Added
- Automatic once-daily operational digest scheduler
- Asia/Kolkata-aware configured run time
- At-most-once generation per local day
- Missed-run catch-up after API restart
- Optional automatic enqueue into notification outbox
- Scheduler status and protected manual-run APIs
- Live Intelligence scheduler status and manual control

## Safety
- Operational reporting only
- Live broker order submission remains disabled
