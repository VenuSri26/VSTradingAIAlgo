# V5.5.0 RC1 — Feed Alerting & Token Health

Cumulative over V5.4.0 RC1.

## Added
- Feed alert evaluator and persisted alert history.
- Critical alerts for authentication failure, disconnection, stale data, old token checks, and repeated failures.
- Warnings for REST fallback, missing expiry, and instrument sync.
- Live Intelligence Feed Alert Center.
- APIs `/api/feed-alerts/status` and `/api/feed-alerts/history`.

Live order submission remains disabled.
