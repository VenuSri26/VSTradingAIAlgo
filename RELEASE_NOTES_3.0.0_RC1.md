# VSTradingAI 3.0.0 RC1

## Included
- Evidence-based production-candidate certification engine.
- Weighted gates for release health, configuration, paper sample size, win rate, profit factor, expectancy, drawdown and risk readiness.
- New `/api/production-candidate/status` and `/api/production-candidate/checklist` endpoints.
- New Production Certification dashboard workspace.
- Live broker orders remain disabled.
- Existing V2.9 learning, V2.8 intelligence and all earlier modules retained.

## Promotion rule
A release is not certified until every gate passes. The minimum evidence target is 30 closed paper trades with positive expectancy, profit factor at least 1.20, controlled drawdown and a healthy release certificate.
