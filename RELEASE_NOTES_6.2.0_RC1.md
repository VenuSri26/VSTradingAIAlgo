# V6.2.0 RC1

Cumulative release based on V6.1.0 RC1.

## Added
- Automatic notification dispatch scheduler.
- Exponential delivery retry with configurable maximum delay.
- Maximum-attempt failure state.
- Critical notification escalation.
- Admin acknowledgement endpoint.
- Scheduler status and manual-run API.
- Live Intelligence scheduler metrics.
- Safe operation when no delivery channel is configured.

Live Zerodha order execution remains disabled.
